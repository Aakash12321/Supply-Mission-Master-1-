# Supply Mission

Drop a supply package from a helicopter and watch it fall to the ground.

## How to play
- Press the **Down arrow** to release the package.

## Run it locally
Browsers block games that load images and scripts straight from disk, so serve the folder with any small web server:

```bash
git clone https://github.com/Aakash12321/Supply-Mission-Master-1-.git
cd Supply-Mission-Master-1-
python -m http.server 8000
```

Then open <http://localhost:8000> in your browser. (The VS Code **Live Server** extension works too.)
